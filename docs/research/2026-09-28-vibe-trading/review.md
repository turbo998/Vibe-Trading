- 工具并行：保持“连续只读可并行、写工具及 MCP 串行”范围，不泛化全部工具。保留现有源码索引；就近增补行号建议非阻断。

- 主 Agent 与 Swarm：保留两种校验强度区别以及“所读路径”的限定，没有添加全仓不存在证明。
- 自我改进与 manifest：保留已核对机制与不宣称全量覆盖的限定；未把工作流记忆说成模型训练。
- MCP 冲突：保留两个相冲突的一手文档位置及有条件实现描述；没有声称全面协议兼容。
- Copilot：保留“应用侧认证顺序与文档有差异，SDK 版本行为需实测”。更细的 token 前缀解析属于非阻断补充，未扩大本文配置教学范围。

- live 下单分类：采纳，改列具体 profile ID，注明同券商还有只读 profile。
- 临时 HOME：采纳，补充创建失败时继承 HOME、降权失败时可继续运行的条件。
